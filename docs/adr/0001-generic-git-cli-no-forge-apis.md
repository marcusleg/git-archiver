# Talk to upstreams only through the `git` CLI, never through forge APIs

Git Archiver fetches every repo by running the `git` CLI against its URL and never calls GitHub's, GitLab's or any other forge's API. That works with any git host, needs no API tokens or rate-limit budgeting, and keeps the app small. The cost is precision: GitHub's REST API reports a DMCA block exactly (HTTP 451 with `block.reason: "dmca"` and the notice URL; see `docs/research/git-archiving-prior-art.md` §3.1), while over git the same block shows up only as a 403 with a `remote:` message. We sort failures into Unavailable versus Fetch failed by git's HTTP status and keep git's message as the reason shown to the person. An optional GitHub REST probe to classify an Unavailable repo stays possible later without changing this decision.
